# Contributing to Asli

Thanks for your interest! Asli is a public-good project — contributions are welcome.

## How to contribute

1. **Fork** the repo and create a feature branch (`git checkout -b feat/your-feature`).
2. Make your changes, keeping PRs focused and small.
3. Run the backend tests: `pytest tests/`
4. Open a pull request with a clear description of what and why.

## Good first issues

- Add support for a new Indian language in `report.py` / `detector.py`
- Improve accessibility of the frontend (WCAG 2.1 AA)
- Add unit tests for ensemble weighting logic

## Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).  
Be kind, be constructive, be inclusive.

## Questions?

Open a GitHub Discussion or file an issue — we respond promptly.
